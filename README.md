# Reaction Time Game

A browser game for measuring reaction speed.

## Features

- Random waiting period
- Reaction time measurement
- Best time tracking

## How to Use

Wait for the green signal and click as quickly as possible.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Start a session and wait for the green signal.
- [ ] Click too early and verify false-start handling.
- [ ] Complete multiple rounds and review the best recorded time.
